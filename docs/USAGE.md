# 使用指南

[返回项目首页](../README.md)

## 浏览与编辑

1. 点击人物头像，只打开头像、简介和关系资料；重复点击同一人物也不会自动打开编辑面板。
2. 点击资料底部的“编辑”，关闭资料弹窗并打开编辑面板。新增人物则直接进入编辑；电脑和手机采用相同规则。
3. 可通过俱乐部、国家、关系菜单组合筛选，也可点击右上角两行“色点＋文字”图例多选关系；点击“清除筛选”恢复完整图谱。
4. 修改只保存在当前浏览器副本中。重要改动请“导出数据”保存 JSON；“保存为 HTML”用于离线分享，“保存为图片”用于展示。

顶部“编辑面板”按钮可在已选择人物后手动切换面板；关闭编辑面板不会删除人物或修改正式网站。

网页、“保存为 HTML”的离线版和“保存为图片”的 PNG 均带有右下角半透明“patri677原创”署名。网页署名不随图谱缩放、平移，不拦截点击。完整图和筛选图均保留署名；这仅标识图谱制作作者，不代表拥有球员照片等第三方资料的版权。署名属于展示标识，不是防篡改或版权认证机制。

PNG 署名会随导出图片的尺寸等比放大，便于整图缩小预览时辨认；位于右下方，下缘与当前导出图谱最底部人物的说明文字下缘对齐，不再额外添加底部署名留白。自定义排布时请为右下角署名留出空间。网页和 HTML 的署名仍采用低调的小字号。

## 打开与恢复当前数据

1. 下载本仓库，双击 `index.html` 在浏览器中打开；构建页面已嵌入正式 JSON 数据。
2. 若需恢复备份或切换到其他数据，点击“导入数据”并选择 JSON。仓库的 `data/人物关系图谱-爱心图.json` 当前包含 60 个人物和 95 条关系；导入会覆盖当前浏览器副本，操作前先保存需要保留的数据。
3. 编辑后请再次“导出数据”保存 JSON 备份。浏览器中的自动保存只属于当前浏览器，不会自动同步到其他设备。

`index.html` 是构建生成的独立页面；当前正式图谱数据以单独的 JSON 文件保存。若需要把浏览器中的最新编辑嵌入单个 HTML，请使用页面的“保存为 HTML”功能；若要更新仓库正式数据，请另外导出 JSON。重新构建会从源码和正式 JSON 重新生成根目录的 `index.html`。

自动保存优先使用 IndexedDB，失败时尝试 localStorage；这些数据只属于当前浏览器。JSON 是可迁移的编辑备份，独立 HTML 可分享导出时的数据和筛选状态，“保存为图片”生成的 PNG 用于展示，不能恢复成可编辑图谱。跨设备迁移需要传递文件，不会自动同步。

## 手机与平板

图谱使用固定坐标，屏幕尺寸变化时等比调整视图，保留手动排布。手机上可单指拖动空白处平移、双指缩放，或使用底部的缩放和“适应画布”按钮。拖动人物可调整位置。

屏幕宽度不超过 900px 时，编辑面板默认折叠，展开后覆盖在画布右侧；工具栏换行并预留空间。筛选菜单会限制在可见屏幕内，顶部操作栏支持横向滚动。横竖屏切换会调整面板状态和画布尺寸。

画布右上角的紧凑两行图例直接显示色点和关系名称，支持即时单选或多选，再次点击取消选择。它与“关系”下拉筛选同步，并保留已应用的俱乐部、国家条件。“全部”只清除关系条件，“清除筛选”清除全部条件。窄屏上颜色栏可横向滑动；手机上也可以通过“关系”菜单筛选。点击人物仅显示资料和关系，点击资料底部“编辑”才打开编辑面板；新增人物直接进入编辑。电脑和手机行为一致。

运行 `node tests/responsive.mjs` 可检查等比适配、菜单边界和手势逻辑。这些检查不能替代 iPhone Safari、Android Chrome 和平板的实机验证。
