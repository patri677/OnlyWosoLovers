# Woso 人物关系图谱

一个可离线打开、编辑和导出的人物关系图谱。页面支持人物与关系编辑、搜索和筛选、拖拽与缩放，以及图片、HTML 和 JSON 导出。

## 打开与恢复当前数据

1. 下载本仓库，双击 `index.html` 在浏览器中打开。
2. 点击页面顶部的“导入数据”，选择 `人物关系图谱-爱心图.json`。这份文件是目前的爱心排布版本，包含 60 个人物和 95 条关系。
3. 编辑后请再次“导出数据”保存 JSON 备份。浏览器中的自动保存只属于当前浏览器，不会自动同步到其他设备。

`index.html` 是程序页面；当前图谱数据以单独的 JSON 文件保存。不要只复制 HTML 后就以为最新排布也会跟着同步。若需要把当前数据嵌入单个 HTML，请先导入 JSON，再使用页面的“下载 HTML”或“保存这一版”功能。

## 项目状态

目前是无需服务器的单文件应用。多人共享与跨设备自动同步尚未实现，后续开发方向见 [项目计划.md](项目计划.md)。

## 公开内容提醒

仓库中的 JSON 含人物关系与头像图像数据。公开仓库中提交的文件可能被他人复制；发布新数据前，请确认图片使用权、关系描述及隐私风险。
